# Release 0.3.0

Atualização visual do **SMTT CIF - Validação** para a etapa de homologação.

Principais alterações sobre 0.2.0:

- página pública simplificada, com conteúdo central e um único card de consulta;
- aplicação da marca oficial da SMTT já utilizada pelo plugin Gestão;
- remoção do cabeçalho escuro e de elementos decorativos que poderiam destoar do portal externo;
- título e orientação da consulta posicionados acima do card;
- estado inicial com orientação, código e botão de validação em uma única área;
- estado válido/inválido integrado ao mesmo card, preservando os dados públicos já definidos;
- aviso de LOCAL / HOMOLOGAÇÃO mantido de forma explícita;
- responsividade revisada para celular;
- nenhuma alteração no protocolo, banco, migrations, sincronização, Ed25519, replay guard ou validação pública.

A alteração é exclusivamente de apresentação da página pública, além da atualização de versão do plugin.
