# Segurança

Não publique vulnerabilidades, credenciais ou dados pessoais em issues públicas. Encaminhe relatos de forma privada ao responsável autorizado pela segurança do sistema.

Antes de publicar, revise código, documentação, imagens, testes, histórico Git e configurações para identificar segredos, dados pessoais e materiais institucionais restritos. Use apenas dados fictícios em demonstrações. Revogue e substitua qualquer segredo exposto.
