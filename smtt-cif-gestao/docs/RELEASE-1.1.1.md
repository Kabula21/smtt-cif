# Release 1.1.1

Revisão visual do template CR80.

- dados dinâmicos sem caixas, fundos ou bordas;
- assinaturas do agente e do superintendente recebem cópia derivada em PNG transparente apenas para composição da carteira;
- remoção de branco/quase-branco e recorte automático de margens da assinatura;
- arquivos biométricos originais permanecem inalterados no armazenamento privado;
- template atualizado para CIF-CR80-2026-03 para forçar nova arte quando a emissão ainda não foi produzida fisicamente.
