# SMTT CIF – Gestão 1.11.0

Revisão visual da área de Relatórios.

- categorias de relatório apresentadas como abas integradas ao conteúdo;
- aba ativa com indicação visual e `aria-current`;
- indicadores de resumo mais compactos;
- exportação CSV movida para o cabeçalho da tabela;
- coluna Ações padronizada como controles discretos;
- filtros, paginação, ordenação, permissões e regras de negócio preservados.

Não há migration de banco nesta versão.
